# Simple KPI Tracking Sheet

## Project Overview

This project focuses on creating a simple, automated KPI tracking sheet using Microsoft Excel and the Sample Superstore dataset.

The dashboard summarizes business performance using key performance indicators and Excel formulas.

## Objectives

* Calculate total revenue.
* Calculate total units sold.
* Calculate average order value.
* Identify the top-selling product.
* Create a clean and professional KPI summary.
* Use formulas that update automatically when new data is added.

## Tools Used

* Microsoft Excel
* Sample Superstore Dataset
* Excel Tables
* Excel Formulas

## KPIs Tracked

| KPI                 | Description                           |
| ------------------- | ------------------------------------- |
| Total Revenue       | Total sales generated from all orders |
| Units Sold          | Total quantity of products sold       |
| Average Order Value | Average revenue per unique order      |
| Top Product         | Product with the highest total sales  |

## Excel Functions Used

* SUM
* COUNTA
* UNIQUE
* SUMIF
* INDEX
* MATCH
* MAX

## Project Outcome

Created an Excel-based KPI summary sheet that organizes raw sales data into business-ready performance indicators.

The workbook includes automated calculations, consistent formatting, and a structured dashboard layout.
